Put your image files directly in this folder.

Example: if you drop in a file called "me.jpg", it becomes reachable at:
  /photos/me.jpg

That's the string you pass to a PolaroidSlot's `src` prop, e.g.:
  <PolaroidSlot src="/photos/me.jpg" caption="me!" />

See the "Adding your own photos" section in the main README for the
full walkthrough.
