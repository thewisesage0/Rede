Put your welcome-sound file in this folder, named exactly one of:
  ae-welcome.mp3
  ae-welcome.ogg
  ae-welcome.wav

It plays automatically the first time the AE's dashboard loads in a
browser tab (once per tab session — it won't replay on every click
between dashboard pages). If the browser blocks autoplay, a small
"🔊 play welcome sound" button appears so it can still be started
with one tap.
